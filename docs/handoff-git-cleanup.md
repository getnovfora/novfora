# Handoff: Remove AI/Claude traces from git history

**Scope:** All branches and tags on `getnovfora/novfora`  
**What's removed:**
- `.claude/` directory from every commit in history
- `Co-authored-by: Claude …` / `Co-authored-by: … anthropic.com` trailer lines from all commit messages
- Any "Generated by Claude" / "Built with Claude" commit message lines
- Any branch names containing "claude" or "ai" (detected and deleted)

**What stays:** `CLAUDE.md` (just a tooling config file, no AI attribution)

---

## Pre-requisites (VPS)

```bash
# Confirm git-filter-repo is available (pip-install if not)
git filter-repo --version 2>/dev/null || pip3 install git-filter-repo

# Confirm GitHub auth works (needs a token with repo+force-push scope)
gh auth status
# or: git ls-remote https://github.com/getnovfora/novfora HEAD
```

---

## Step 1 — Fresh bare clone

```bash
cd /tmp
rm -rf novfora-gitclean
git clone --bare https://github.com/getnovfora/novfora.git novfora-gitclean
cd novfora-gitclean
```

> `git filter-repo` requires a fresh clone with no uncommitted work; the bare clone satisfies this.

---

## Step 2 — Write the commit-callback script

```bash
cat > /tmp/clean_commits.py << 'PYEOF'
import re

msg = commit.message.decode('utf-8', errors='replace')
lines = msg.split('\n')
filtered = []
for line in lines:
    lower = line.lower().strip()
    # Drop Co-authored-by lines mentioning Claude or Anthropic
    if lower.startswith('co-authored-by') and ('claude' in lower or 'anthropic' in lower):
        continue
    # Drop "Generated/Built by/with Claude" lines
    if re.match(r'(?:generated|built) (?:by|with) claude', lower):
        continue
    filtered.append(line)

# Rebuild — strip trailing blank lines, preserve final newline
msg = '\n'.join(filtered).rstrip('\n') + '\n'
commit.message = msg.encode('utf-8')
PYEOF
```

---

## Step 3 — Run git-filter-repo

```bash
git filter-repo \
    --path-regex '^\.claude(/|$)' --invert-paths \
    --commit-callback "$(cat /tmp/clean_commits.py)" \
    --force
```

This does two things in one pass:
- **`--path-regex '^\.claude(/|$)' --invert-paths`** — removes the `.claude/` directory from every commit in every branch
- **`--commit-callback`** — rewrites commit messages to strip AI attribution lines

---

## Step 4 — Verify before pushing

```bash
# Check last 20 commit messages for any remaining attributions
echo "=== Checking for remaining Co-authored-by Claude/Anthropic ==="
git log --all --format="%B" | grep -iE "(co-authored-by.*(claude|anthropic))" && \
    echo "⚠️  Still found some — review above" || \
    echo "✓  None found"

# Confirm .claude/ is gone from HEAD of each branch
echo ""
echo "=== Checking .claude/ is removed from all branch HEADs ==="
for ref in $(git for-each-ref --format='%(refname:short)' refs/heads/); do
    if git ls-tree -r "$ref" --name-only | grep -q '^\.claude'; then
        echo "⚠️  $ref still contains .claude/"
    else
        echo "✓  $ref — .claude/ absent"
    fi
done

# Spot check branch names for "claude" or "ai"
echo ""
echo "=== Branch names to review ==="
git for-each-ref --format='%(refname:short)' refs/heads/ | grep -iE "(claude|[^a-z]ai[^a-z]|^ai)" || echo "✓  No suspicious branch names"
```

If any branch names need deleting:
```bash
# Delete a branch locally (it was already rewritten; this just removes the ref)
git branch -D <branch-name>
# Then delete it on GitHub after the push with:
# git push origin --delete <branch-name>
```

## Step 5 — Re-add origin and force-push

> `git filter-repo` removes the `origin` remote by design (safety measure). Re-add it before pushing.

```bash
git remote add origin https://github.com/getnovfora/novfora.git

# Push all rewritten branches and tags
git push origin --force --all
git push origin --force --tags
```

## Step 6 — Post-flight check on GitHub

```bash
# Fetch a fresh view and confirm no .claude/ on main
git clone https://github.com/getnovfora/novfora.git /tmp/novfora-verify
ls /tmp/novfora-verify/.claude 2>/dev/null && echo "⚠️  .claude still present" || echo "✓  .claude/ absent"

# Spot check last 10 commit messages on main
cd /tmp/novfora-verify
git log --format="%s%n%b" -10 | grep -iE "(co-authored-by.*(claude|anthropic)|generated by claude)" && \
    echo "⚠️  Attribution still present" || \
    echo "✓  No AI attribution in last 10 commits"
```

## Notes

- **GitHub cache:** old commits remain reachable by their old SHA for ~90 days (GitHub GC). If you need them purged faster, contact GitHub Support and request a GC run after the force-push.
- **Working directory:** `/tmp/novfora-gitclean` — safe to delete once the verify step passes.
- **CLAUDE.md:** intentionally left in the repo (just a tooling config, no attribution content).
- **Model rung:** this is a mechanical shell script, Sonnet is fine to execute it.
