What you need

The baseline requirements

🐘

PHP 8.3+

With the standard extensions (pdo_mysql, mbstring, openssl, zip, gd or imagick for images).

🗄️

MySQL or MariaDB

An empty database you create in your host's control panel. PostgreSQL on the enhanced tier.

⏱️

One cron job

A single scheduled command every 1–5 minutes powers email, digests, upgrades, and backups.

Install in minutes

From upload to live in four steps

Upload & point your domain

Extract the release above your web root and point the domain at public/. Subfolders like /community are first-class too.

Run the web installer

Visit your site — every URL redirects to the installer. System check, paste the setup token, enter your database, create your admin.

Add the cron line

Paste the one cron command from the completion screen into your host's control panel. That's the engine for everything time-based.

You're live

The installer seals itself, you log in, and you're shaping forums. Configure mail in .env and you're ready to open.

When you scale

Light up the enhanced tier

Move to Docker or a VPS and NovFora picks up the better infrastructure automatically — no data migration, just speed and headroom.

⚡

Redis + workers, Meilisearch

Real queue workers replace cron draining, and typo-tolerant ranked search replaces full-text — same UX, more scale.

📡

WebSockets + S3 + provider email

Live updates over WebSockets, media on S3/MinIO, and high-volume email via SES/Postmark. Detected and used automatically.
